# アグリコラ スコア記録アプリ

ボードゲーム「アグリコラ」の得点計算を、写真を使って記録するスマホ向けWebアプリ (PWA) です。

## 主な機能

- **新規ゲーム作成**: プレイヤー名(最大5人)を入力してスコア入力を開始
- **ボード得点**: 農場ボードの畑・牧場・穀物・野菜・羊・猪・牛・部屋・家族の人数・物乞いトークンなどを入力すると、公式スコアシートのルールに沿って自動集計。参考用にボードの写真も添付でき、写真は回転・切り抜き(色はそのまま)して見やすく調整できます(後から「編集」で撮り直しなしに再調整も可能)
  - 畑・牧場・柵付き小屋・穀物・野菜・羊・猪・牛・部屋数・家族の人数は、各項目の📷ボタンから**写真に写ったコマの数を自動でカウント**させ、その数を入力欄に反映することもできます(その場で数を手直しすることも可能)
- **カード得点**: 職業カード・進歩カードをカメラで撮影 → カード名が写る部分を指で囲んで範囲指定 → 端末内でOCR (Tesseract.js, 日本語) によりカード名を読み取り → ローカルのカードデータベースと照合して得点を自動入力
  - カード名の範囲を指定することで、イラストや背景に惑わされず認識精度が上がります(囲まず全体で読み取ることも可能)
  - **複数枚のカードを1枚の写真でまとめて認識**できます。各カードの名前部分だけが見えるように並べて(他の部分は別のカードで隠すなど)撮影すると、読み取れた行ごとに1枚のカード候補として一覧表示されます。名前・種類・得点をその場で確認・修正し、不要な行はチェックを外してから「まとめて追加」できます
  - 未登録のカードは初回のみ得点を手入力すると、カード名とともに端末に記憶され、次回から自動計算されます
- **記録の保存・閲覧**: 各ゲームの結果はブラウザのIndexedDBにローカル保存され、いつでも履歴を確認できます(サーバー通信・アカウント登録は不要)

## 技術構成

- React + TypeScript + Vite
- `vite-plugin-pwa` によるPWA化(ホーム画面に追加してオフラインでも起動可能)
- `tesseract.js`: ブラウザ内で完結するOCR(初回のカード認識時に言語データをダウンロードするためインターネット接続が必要です。以降はキャッシュされます)。認識前に、囲んだ範囲へ自動で少し余白を足してからぼかし+Otsu法で白黒二値化し、さらに枠の端に接している(=文字ではなくカードの縁の色がはみ出ただけの)黒領域を除去してから読み取ることで精度を上げています(余白を自動で足すのは、文字ギリギリで囲んでも文字自体が消えないようにするためです)。読み取れなかった場合は自動で90度ずつ回転して再試行し、二値化の結果がうまくいかない場合は「白黒化せずに読み取り直す」ボタンで別処理を試すこともできます
- `fuse.js`: OCR結果とカードデータベースのあいまい一致検索
- `dexie` (IndexedDB): ゲーム記録・カードデータベースのローカル保存

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## 注意事項・既知の制約

- **ボード得点の自動カウントについて**: 各項目の📷ボタンは、囲んだ範囲の中で「背景(机・ボード)と大きく色が違う塊」を自動で数える簡易的な機能です。文字認識(OCR)とは別の仕組みで、アグリコラのコマを認識する専用のAIモデルではなく、農場ボードはプレイヤーごとにレイアウトが自由なため汎用の物体検出モデルも使えません。色の判定だけを使った目安のカウントなので、コマ同士が接していたり影が濃いと少なく数えたり、光の反射などを多く数えたりすることがあります。検出結果は赤枠付きの写真と一緒に表示されるので、必ず見比べてから数値を確認・修正してください。この機能を使わず、写真を見ながら手動で数を入力することももちろん可能です。
- **カード得点について**: 職業カード・進歩カードは効果や得点条件がカードごとに異なり、フルセットの点数ルールを正確に事前登録するとかえって誤集計のリスクがあるため、あらかじめ登録済みなのは得点が固定で分かりやすい一部のカード(例: 井戸 = 4点)のみです。それ以外のカードは、初回にカードの得点をユーザーが入力すると、以後は自動計算されます。カードデータベースはブラウザのIndexedDB内で育っていきます。
- **データはすべて端末内ローカル保存**です。ブラウザのデータを消去すると記録も失われるため、必要に応じて別途バックアップ手段の追加を検討してください。
