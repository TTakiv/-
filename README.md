# アグリコラ スコア記録アプリ

ボードゲーム「アグリコラ」の得点計算を、写真を使って記録するスマホ向けWebアプリ (PWA) です。

## 主な機能

- **新規ゲーム作成**: プレイヤー名(最大5人)を入力してスコア入力を開始
- **ボード得点**: 農場ボードの畑・牧場・穀物・野菜・羊・猪・牛・部屋・家族の人数・物乞いトークンなどを入力すると、公式スコアシートのルールに沿って自動集計。参考用にボードの写真も添付でき、写真は回転・切り抜き(色はそのまま)して見やすく調整できます(後から「編集」で撮り直しなしに再調整も可能)
- **カード得点**: 職業カードと進歩カードをそれぞれ別のセクションで管理します(合計点もカードの種類ごとに表示)。「+カード追加」→ カメラで撮影 → Google Gemini(AI)がカード名を読み取り → ローカルのカードデータベースと照合して得点を自動入力
  - **複数枚のカードを1枚の写真でまとめて認識**できます。写っているカードの名前を順番にすべて抽出し、読み取れたカードごとに1件の候補として一覧表示されます。名前・得点をその場で確認・修正し、不要な行はチェックを外してから「まとめて追加」できます
  - 未登録のカードは初回のみ得点を手入力すると、カード名とともに端末に記憶され、次回から自動計算されます
  - この機能にはインターネット接続と、Gemini APIキーを設定したCloudflare Worker(`worker/`フォルダ参照)のセットアップが必要です。未設定の場合や通信エラー時は手動入力にフォールバックします
- **記録の保存・閲覧**: 各ゲームの結果はブラウザのIndexedDBにローカル保存され、いつでも履歴を確認できます(サーバー通信・アカウント登録は不要)

## 技術構成

- React + TypeScript + Vite
- `vite-plugin-pwa` によるPWA化(ホーム画面に追加してオフラインでも起動可能)
- カード名の読み取りは Google Gemini API を使用。APIキーを安全に扱うため、キー自体はアプリに含めず、`worker/gemini-proxy.js` としてCloudflare Workers(無料)にデプロイした中継サーバー経由で呼び出します。詳しい設置手順は `worker/README-deploy.md` を参照してください
  - Google Cloudプロジェクトに請求先アカウント(クレジットカード)を紐付けない限り、無料利用枠を超えたリクエストは失敗するだけで課金は発生しません
- `fuse.js`: 読み取ったカード名とカードデータベースのあいまい一致検索
- `dexie` (IndexedDB): ゲーム記録・カードデータベースのローカル保存

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## 注意事項・既知の制約

- **ボード得点の自動撮影認識について**: 農場ボード上の資源コマや畑・柵の配置を写真から自動で「数える」のは、文字認識(OCR)だけでは実現できません。そのため現在は「写真を見ながら数を入力すると点数を自動計算する」方式です。写真自体は記録用として添付できます。
- **カード得点について**: 職業カード・進歩カードは効果や得点条件がカードごとに異なり、フルセットの点数ルールを正確に事前登録するとかえって誤集計のリスクがあるため、あらかじめ登録済みなのは得点が固定で分かりやすい一部のカード(例: 井戸 = 4点)のみです。それ以外のカードは、初回にカードの得点をユーザーが入力すると、以後は自動計算されます。カードデータベースはブラウザのIndexedDB内で育っていきます。
- **データはすべて端末内ローカル保存**です。ブラウザのデータを消去すると記録も失われるため、必要に応じて別途バックアップ手段の追加を検討してください。
